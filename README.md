## 在自由工坊的位置

[自由工坊](https://freetwai.com) 讓會員先完成定位、選擇公會並領取 Repo 技能書，再以供貨、商店、開源作品、行銷與小隊共同完成成果。

公開技能與作品的宣告入口及匯入轉換工具。 已有 project import helpers、manifest 轉換、starter-skill 與空的 PR 維護宣告清單。

技能安裝、能力驗證、版本自動同步與正式審核轉移尚未實作；空清單不是平台沒有技能書。

本 repo 的維護者負責「公開技能與作品的宣告入口及匯入轉換工具。」這個模組；公會職稱與自填 GitHub slug 不授予寫入權。

程式／內容入口：[src/index.mjs](src/index.mjs)、[registry/packages.yaml](registry/packages.yaml)、[templates/starter-skill/](templates/starter-skill/)、[scripts/check-registry.mjs](scripts/check-registry.mjs)、[test/](test/)。協作先讀 [CONTRIBUTING.md](CONTRIBUTING.md)，讓 Agent 讀 [AGENTS.md](AGENTS.md)；從[本倉 Issues](https://github.com/FreeTWAI/freedom-skill-registry/issues)認領、[查看既有 PR](https://github.com/FreeTWAI/freedom-skill-registry/pulls)避免重工。

GitHub 擁有原始碼；中央平台重新讀 GitHub 並保存 import evidence。此 repo 的宣告不會自行建立會員、授予技能或把作品標為官方。 跨 repo 的協定由[中央平台](https://github.com/FreeTWAI/freedom-platform)維護。

Public import declarations and starter material for skills and open projects. GitHub owns source code; Freedom Platform owns membership, imported project records, review evidence and state. This repository has no database.

## Run

Use Node 24: `npm test` and `npm run build`. No dependency installation is needed for the native tests. `registry/packages.yaml` uses JSON serialization (valid YAML) and is intentionally empty: no package has been reviewed or accepted through this registry yet.

## Connect

Use the exact pinned client under `vendor/freedom-platform/` with an authorized Platform session. `src/index.mjs` exports:

- `listRegisteredProjects(client)` → `client.call('listProjects')`.
- `registerProject(client, body, { idempotencyKey })` → `client.call('importProject', ...)`.
- `projectManifestToImport(manifest, { relationship, consentToShare: true, useNotes })` maps explicit public identity into the existing project import command. Validate the complete manifest against the pinned schema first. The Platform re-reads GitHub and pins its observed source version; client-provided IDs do not replace that verification.

Re-use an idempotency key only when retrying the same command. Changing a registry declaration does not perform an import. The current API supports **open project** registration; skill-package capability validation, installation, version sync and official review transitions remain future work. Documentation starters do not imply those capabilities exist.

## Boundaries

`registry/packages.yaml` is a PR-controlled list of requested imports, not another state database. A declaration contains `package_id`, public `repository_url`, exact `commit`, root `manifest_path: freedom-skill.yaml`, and `intent: request_import`. It grants no ownership, rank, execution permission or payment rights. No credentials, private manifests or customer files belong here. Public pages are generated by `freedom-project-page`; neither build nor import publishes them automatically.
